# Screenshots

Add visual screenshots and demos here to showcase Vibe Visual features.

## Suggested Screenshots

- **default-view.png** - Default appearance with sample data
- **custom-colors.png** - Visual with customized bar and axis colors
- **with-labels.png** - Visual showing data labels on bars
- **hover-state.png** - Bar with hover effect applied
- **cross-filter-demo.gif** - Animated GIF showing cross-filtering in action
- **formatting-pane.png** - Screenshot of the formatting options panel
- **responsive-demo.gif** - Visual resizing demonstration

## How to Capture

1. Import the visual into Power BI Desktop
2. Add sample data from `../sample-data.csv`
3. Configure various formatting options
4. Use Windows Snipping Tool or similar to capture screenshots
5. Add files to this directory
6. Update the main README.md to display screenshots

## Naming Convention

Use descriptive, kebab-case names:
- `feature-name-view.png` for static screenshots
- `feature-name-demo.gif` for animations
- Include visual version in filename for version-specific screenshots

Example: `v1.0-default-view.png`
